Privacy policy

Last updated: 10 November 2026

Personal Agents is a private, single-user tool. Its only user is the owner of the Google account it is connected to.

What data it accesses

With the owner's permission, it reads message metadata (sender, subject, date, labels, unsubscribe headers) from the owner's own Gmail. It adds labels, moves messages the owner has approved to Gmail's Bin, and places a daily summary in the owner's own inbox.

Where data is stored

Everything is stored only on the owner's own computer. Nothing is sold, shared, or used for advertising. Short text excerpts may be sent to the Anthropic API for summarisation under Anthropic's commercial terms.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove access at any time at myaccount.google.com/permissions.
